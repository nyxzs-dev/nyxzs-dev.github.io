# nyxzs.dev portfolio

Static Roblox developer portfolio prepared for GitHub Pages.

## Edit the website

Edit `content.json` to change the name, role, contact links, summary, or projects. Commit the change on GitHub and GitHub Pages will publish it automatically.

## Publish with GitHub Pages

1. Create a public repository named `<your-github-username>.github.io`.
2. Upload every file in this folder to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**, choose `main` and `/ (root)`, then save.

Your free site address will be `https://<your-github-username>.github.io`.
